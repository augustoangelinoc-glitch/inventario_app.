# 📦 Control de Inventarios y Abastecimiento (Versión Mejorada)

Aplicación web (Streamlit) que automatiza el análisis de stock, consumo histórico,
pronóstico de demanda y cálculo de abastecimiento a partir de dos archivos Excel.

## 🚀 Características nuevas

- ✅ **Parámetros configurables por Familia o Producto** (sin perder los globales)
- ✅ **Preservación de ceros a la izquierda en códigos** (P001, P002, etc.)
- ✅ **Detección automática de anomalías** (picos, salidas únicas)
- ✅ **Exclusión de anomalías del cálculo de compra**
- ✅ **Pronóstico automático** (SES, Holt, Holt-Winters) con selección del mejor método
- ✅ **Detección de rotura de stock** (stock ≤ 0 con salidas)
- ✅ **Inconsistencias tabuladas con cantidades afectadas**
- ✅ **Comentarios explicativos en cada indicador**
- ✅ **Exportación a Excel con 11 hojas**
